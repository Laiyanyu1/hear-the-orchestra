# 听见管弦乐队

《听见管弦乐队》是一款可离线使用的西洋管弦乐器音色课堂工具，包含 18 种常见乐器。

## 功能

- 按木管组、铜管组、打击乐器、弦乐组、色彩乐器分类学习
- 点击乐器图片试听真实演奏录音
- 查看演奏方式与音色特征
- 随机听辨答题
- A/B 音色对比
- 拖拽分类练习
- 老师导入 MP3 / WAV 替换课堂音频

直接打开 `index.html` 即可使用，无需联网。

## 素材来源

- 17 件乐器录音来自 [Philharmonia Orchestra Sound Samples](https://philharmonia.co.uk/resources/sound-samples/)。官方许可允许免费使用，但不得将原始采样作为独立采样库出售或原样提供。
- 钢琴录音来自 [Wikimedia Commons: E major piano.ogg](https://commons.wikimedia.org/wiki/File:E_major_piano.ogg)，采用 CC0 许可。
- 乐器配图来自对应的 Wikipedia / Wikimedia Commons 条目，逐件链接见网页“音频与出处”页面。
